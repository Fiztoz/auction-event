2.2 Signup Flow

1
Navigate to /app
Guest sees Signup Screen (Step 1 of 3). Form: Name, Email, Password (min 8 chars).
2
POST /api/signup
Backend validates email format, password length, name presence, and email uniqueness. Creates user with role: "buyer", step: "verify_email", bcrypt hash, UUID ID.
3
Token notification
6-digit token generated (15-min TTL). Logged to stdout via StdoutNotifier. Session cookie established. Event: UserSignedUp.
4
Auto-advance
Frontend shows Verify Email Screen (Step 2 of 3). User must enter the 6-digit code from logs.

3.3 Bid Rules

⚡ Validation Rules
  • Who can bid: Any signed-in user (not the seller)
  • When: Auction is live AND before ends_at
  • First bid: Must be ≥ starting_price_cents
  • Subsequent bids: Must strictly exceed current_bid_cents
  • Amount: Positive integer (cents)
  • Denormalization: current_bid_cents, highest_bidder_id, bid_count stored on product
  • Audit: Full bid history in bids collection (newest-first)

10.3 Frontend Stack

⚡ Vue 3 SPA Architecture
  • Framework: Vue 3 Composition API via CDN
  • Modules: Native ES modules (no build step)
  • State: Reactive singleton (store.js)
  • Events: Tiny pub/sub bus (events.js) with on() / emit()
  • API: api.js (JSON) + apiUpload.js (multipart)
  • Components: One screen per file, route-based rendering
  • Subscriber: console-logger.js logs all events
